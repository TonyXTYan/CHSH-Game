# User Guide

Welcome to the CHSH Game user guide! This section provides everything you need to know to play and enjoy the game.

## What is the CHSH Game?

The CHSH Game is an interactive web application that demonstrates concepts related to the Clauser-Horne-Shimony-Holt (CHSH) inequality, a fundamental concept in quantum mechanics and Bell's theorem. Players work in teams to answer questions and explore the fascinating world of quantum correlations.

## Getting Started

### Quick Start
1. **Open the game** - Navigate to the participant page
2. **Create or join a team** - Enter a team name or select an existing team
3. **Wait for your partner** - Teams need exactly 2 players
4. **Play the game** - Answer True/False questions based on your strategy
5. **View results** - Check your team's performance on the dashboard

### What You'll Need
- A web browser (Chrome, Firefox, Safari, or Edge)
- Internet connection
- A partner to form a team of 2 players
- A strategy discussion with your partner (before the game starts!)

## Game Components

### Player Interface
- **Team creation/joining** - Simple interface to form teams
- **Question display** - Shows your assigned question (A, B, X, or Y)
- **Answer buttons** - True/False response options
- **Status updates** - Real-time feedback on game state

### Dashboard (for instructors/hosts)
- **Game controls** - Start, pause, and reset functionality
- **Live statistics** - Real-time team performance metrics
- **Answer log** - Stream of all player responses
- **Data export** - Download results as CSV
